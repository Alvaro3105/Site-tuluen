# Tuluen — Projeto Web

Projeto acadêmico de front-end desenvolvido para praticar criação de um site multipágina com **HTML e CSS**, incluindo páginas institucionais e galeria de imagens.

## Tecnologias

- HTML5
- CSS3

## Estrutura

O projeto inclui páginas como:

- Home
- About
- Contact
- Gallery

Além de pastas com imagens e assets utilizados na interface.

## O que o projeto pratica

- navegação entre páginas;
- composição de layouts;
- galerias de imagens;
- tipografia e espaçamento;
- formulários e conteúdo institucional;
- responsividade.

## Como executar

1. Clone o repositório.
2. Abra `index.html` no navegador.

## Contexto

Projeto criado durante a formação técnica em TI como exercício de desenvolvimento web.
